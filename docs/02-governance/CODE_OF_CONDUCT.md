# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

---

## TL;DR

- Be respectful. Disagree on ideas, not on people.
- Assume good intent. Ask before accusing.
- No harassment, discrimination, or personal attacks.
- Keep discussion focused on the work.

## Reporting

If something violates this code, contact the maintainer (see [CODEOWNERS](../../CODEOWNERS)). Reports are confidential.

## Enforcement

Maintainer can:
- Ask the contributor to revise comments
- Lock a thread
- Revoke contribution access
- Ban (escalation only, with reasoning recorded)

Decisions are final but appealable in writing to the same maintainer once.
